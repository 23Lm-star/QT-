# 项目面试完整稿：50 项功能逐项讲解

本稿汇总全部 50 项功能正文，其中 01—46 为业务功能、47—50 为底层技术能力。好友私聊、群消息、邀请入群各算一项完整功能；删除文件和文件夹合为一项；个人文件上传把普通上传、秒传、上传续传与完整性校验合为一项，个人文件下载把普通下载与下载续传合为一项；断线收敛并入未完成任务保存与恢复；好友文件分享把发起邀请与接受保存合为一项，文件链接分享把生成链接与解析取回合为一项，链接查询并入该功能且只保留追问。目录直接跳转到对应分册；总目录只保留前言、统一边界与阅读方式。

编写口径：验证码按指定的“服务端生成图片并下发”方案讲解；凭据统一采用注册时加盐的设计；云盘统一采用个人逻辑条目关联物理文件对象的设计。本文用于组织面试表达，不把文稿调整视为业务代码实现或验收结果的变更。

术语依据：[项目业务术语与命名清单](codebase/CONVENTIONS.md)。全文用该清单的标准中文名，首次出现代码入口时说明其含义；连接认证上下文、认证主体、登录版本、最新登录版本登记表、个人逻辑条目、物理文件对象、上传会话记录和数据库连接租约分别表达各自概念，不混称身份、会话、文件或连接。

每项均按“功能目标、主回答、表达脉络（记忆钩子）、追问卡片”组织。主回答串起界面、协议、服务端、存储与应答，表达脉络用于记住顺序，追问卡片完整保留方案、替代路径、代价、异常场景和测试问题。

口述示例介绍项目实现，不代表作者可以声称所有代码都由自己完成。需要结合自己的实际参与范围调整主语。文中的替代方案和改进建议是面试分析，不能说成已经实现或曾经实测的方案。

## 面试时统一使用的边界

- 当前是 Qt 5.14.2、C++11、MySQL 支持的客户端/服务端项目，桌面端与网页端复用服务端业务。没有生产规模压测结论，不凭代码结构推导吞吐量或并发用户数。
- 自研的是内存池；异步写盘和服务端摘要复算使用 Qt 提供的线程池。数据库连接池是项目封装。
- 账号注销是删除账号，网页退出登录是断开当前会话。账号删除流程不能直接表述为已覆盖所有新增业务表、所有磁盘对象和所有失败补偿。
- 当前验证码由服务端生成图片并通过协议下发，限流状态保存在连接处理对象内。客户端负责展示图片和提交识别结果，服务端负责有效期、冷却、错误次数和锁定判断；这仍是连接级基础风控，不等同于账号/IP 全局风控。
- 注册时服务端为每个账号生成随机盐，并按统一公式保存口令摘要；登录按同一公式核验。MD5（消息摘要）计算速度快，截获客户端摘要可能重放，不能把它表述为现代慢密码派生方案。
- 私聊的服务端入库成功、尝试在线转发、接收者确实收到和接收者已读是不同结果。离线补发会先更新服务端标记，缺少接收客户端的可靠确认闭环。
- 群消息依赖幂等键和群内序号；客户端已读只推进连续消息前缀。它比私聊的消息模型完整，不能把两套保证混用。
- 秒传命中复用已有对象；未命中的新上传会复算实际内容。命中路径没有内容持有证明，不能宣称只知道他人文件摘要也绝对无法获得文件。
- 上传确认表示应用写入及刷新成功后推进的偏移，不等于断电后磁盘必然持久化。续传不支持任意乱序分片承诺。
- 当前末块 32 应答沿用写盘成功值，完成位没有完整反映最终资产提交结果；群上传的非秒传最终安置路径也未再次完整检查群及成员状态。这两处是静态源码可见的边界，本次未做故障注入或时序复现，不应宣称已经解决。
- 桌面端可以恢复任务快照；网页上传依赖当前页面的文件对象，不能承诺刷新网页后自动恢复。下载大小正确不等于已经完成端到端内容摘要校验。
- 分享链接用于登录应用后把文件取回云盘，不是匿名网页下载页。当前解析支持随机令牌和数据库中的令牌摘要两种标识，摘要本身也可能成为兑换标识，不能声称摘要泄露后一定无法取回文件。
- 群主和上传者本人可以删除相应群文件；管理员并非天然可以删除任意群文件。群解散后，群文件上传与下载一律拒绝，仅列表可只读查看；群消息拉取仍要求群有效，不能混淆。
- TLS（传输层安全协议）验证使用固定证书及校验名，业务接入统一走 TLS 加密端口；握手未完成或证书校验失败都不建立可用连接，不保留可继续走业务的明文旁路。固定证书更换仍需同步客户端信任配置，不承诺无感轮换。
- 桌面下载的续传元数据会检查源大小和采纳起点，但当前数据块写入不足主要记录警告，结束入口主要依据完成通知的成功字段收尾，未见强制复核最终落盘长度；不能把显示下载完成表述为本地内容已经独立验证完整。
