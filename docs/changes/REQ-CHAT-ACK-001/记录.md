对应 PRD「REQ-CHAT-ACK-001」。已完成：协议 109—116、服务端 ACK 落库与能力分流、桌面端 109/112 处理与 110 回执、好友申请离线登记与 113/114/115 全链路。未做：网页端改造、GUI 人工验收。

## 计划与重要决定

- 协议只追加 109—116，15/17/18 布局与语义不动；网页端零改动。
- 送达判据从「服务端写出成功」改为「客户端 110 确认（消息 ID + 收件人双条件）」，防止伪造 ID 越权标记。
- 用 116 能力声明区分桌面端与网页/旧端，避免网页端实时私聊失效，也避免旧断言（在线投递后 17 不重复返回）被破坏。
- 好友申请去掉「目标必须在线」限制；申请方返回 `ret=2`（新增码，不与既有 1/0/-2 冲突）。
- 拒绝申请新增 115，把 pending 置 `rejected`，避免每次刷新重复弹窗。
