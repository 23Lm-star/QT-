# REQ-PROTO-CODE-001｜协议处理结果标准码统一

## 目标与当前进展

把服务端、桌面客户端和网页端的处理结果统一为同一套标准码。已完成 C++ 两端协议枚举、服务端响应写入、网页端返回码与字段偏移调整，以及协议冒烟夹具同步。

## 计划与重要决定

- 不新增消息编号，标准码追加到两端 `protocol.h`。
- 成功码为 `0`，已受理为 `1`，失败按认证、好友、分享、群、参数、验证码、文件和传输领域使用负数。
- 服务端响应统一写入 `caData[0,4)`。98、41、53、55、57 等受影响响应的网页解析按新偏移和标准码读取。
- Server、Client 和网页端必须一起使用，旧网页或旧桌面端不能与新服务端混用。
